🌤️ Weather App 
A simple weather application that allows users to search for real-time weather updates by entering a city name. Built with HTML, CSS, and JavaScript, this app fetches data from a weather API and displays key weather details in a user-friendly interface.

🚀 Features
✅ Search for Weather – Users can enter a city name to get the latest weather updates.
✅ Display Weather Details – Shows essential weather information:

🌡️ Temperature
💧 Humidity
💨 Wind Speed
☁️ Weather Description (e.g., sunny, cloudy)
✅ Weather Icon – Displays an icon representing the current weather (e.g., 🌞, 🌧️, ⛅).
✅ Error Handling – Displays a friendly error message if the city is not found.

🖥️ Tech Stack
HTML – Structure
CSS – Styling
JavaScript – Logic & API calls
Weather API – Fetches real-time weather data
